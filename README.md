總題數：151 cases  
其中新增 30 題「模糊情境病例」，並將 IM11、IM30 納入 mystery pool。

## 核心改版
- 新增「🕵️ 模糊題」模式。
- 主訴改用病人／家屬語言，不先給典型診斷關鍵詞。
- Real OSCE 模式的題目下拉選單不再顯示病例 title，避免作答前被劇透。
- 同一類主訴可對應不同診斷，需靠 History、PE、Investigation 拆解。
